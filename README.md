# 🧮 Verilog Half Adder Circuit

A fundamental combinational circuit that performs binary addition of two 1-bit numbers, producing a **Sum** and a **Carry**. Designed in Verilog HDL and verified using **Questa-Altera Starter FPGA Edition**.
